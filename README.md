# Регистр сведений в 1С: связь справочников и вывод данных через запрос

Учебный проект для начинающих 1С-разработчиков. На простом примере показывает, как:
- организовать **связь двух справочников** через регистр сведений;
- **заполнить регистр** данными;
- **вывести данные** из регистра на форму с помощью запроса;
- понять, как работают **ссылки** и **таблицы значений** в 1С.

## 🎯 Цель проекта

Показать начинающим программистам, что регистр сведений — это не «страшная сущность», а простой механизм хранения связей между объектами. На примере «Ученик — МестоЖительства» разобрано, как:
1. Создать справочники.
2. Создать регистр сведений.
3. Связать справочники через регистр.
4. Вывести связанные данные на форму через запрос.

## 📋 Что нужно для работы

- Платформа **1С:Предприятие 8.3** (учебная версия подойдёт).
- Конфигуратор 1С.
- Базовое понимание: что такое справочник, форма, обработка.

## 🏗️ Структура проекта

### Справочники

| Справочник | Реквизиты | Назначение |
|---|---|---|
| **Ученики** | Наименование, ДатаРождения | Список учеников |
| **Поселки** | Наименование | Список населённых пунктов |

### Регистр сведений

| Регистр | Режим | Измерения | Ресурсы |
|---|---|---|---|
| **Регистратор** | Подчинённый регистратору | Ученик (СправочникСсылка.Ученики), Поселок (СправочникСсылка.Поселки) | — |

**Что это даёт:** регистр хранит связь «ученик → посёлок». Один ученик может жить в нескольких посёлках (история), один посёлок — содержать много учеников. Это классическая связь **«многие ко многим»**, реализованная через промежуточный регистр.

### Обработка «Просмотр регистра»

Форма с кнопкой и таблицей. По нажатию кнопки:
1. Выполняется запрос к регистру.
2. Результат выводится в таблицу на форме.

## 🚀 Пошаговый ход работы

### Шаг 1. Создание справочника «Ученики»

1. В Конфигураторе: **Справочники → Добавить**.
2. Имя: `Ученики`.
3. Добавить реквизиты:
   - `ДатаРождения` (Дата).
4. **F7** — обновить конфигурацию.

### Шаг 2. Создание справочника «Поселки»

1. **Справочники → Добавить**.
2. Имя: `Поселки`.
3. **F7** — обновить конфигурацию.

### Шаг 3. Создание регистра сведений «Регистратор»

1. **Регистры сведений → Добавить**.
2. Имя: `Регистратор`.
3. В свойствах:
   - **Режим**: `Подчинённый регистратору`.
   - **Периодичность**: `По регистратору` (или `Непериодический` — по задаче).
4. Добавить **измерения**:
   - `Ученик` — тип `СправочникСсылка.Ученики`.
   - `Поселок` — тип `СправочникСсылка.Поселки`.
5. **F7** — обновить конфигурацию.

**Что это даёт:** регистр хранит записи вида «Ученик X живёт в Посёлке Y», привязанные к документу-регистратору.

### Шаг 4. Создание обработки «Просмотр регистра»

1. **Обработки → Добавить**.
2. Имя: `ПросмотрРегистра`.
3. **Готово**.

### Шаг 5. Создание формы обработки

1. Раскрыть `ПросмотрРегистра → Формы`.
2. **Добавить → Форма обработки**.
3. **Готово**.

### Шаг 6. Добавление элементов на форму

На вкладке **Элементы**:

1. **Добавить → Кнопка**:
   - Имя: `Показать`.
   - Заголовок: `Показать данные`.
2. **Добавить → Таблица**:
   - Имя: `ТаблицаРегистра`.
   - Заголовок: `Данные регистра`.

На вкладке **Реквизиты**:

1. **Добавить** реквизит:
   - Имя: `ТаблицаРегистра`.
   - Тип: `ТаблицаЗначений`.
2. В реквизите добавить колонки:
   - `Ученик` — тип как у измерения (СправочникСсылка.Ученики).
   - `Поселок` — тип как у измерения (СправочникСсылка.Поселки).

**Связать таблицу на форме с реквизитом:** в свойствах элемента `ТаблицаРегистра` поле **Данные** = реквизит формы `ТаблицаРегистра`.

### Шаг 7. Код кнопки

Двойной клик по кнопке → создастся процедура. Вставить:

```bsl
&НаКлиенте
Процедура Показать(Команда)
    ПоказатьНаСервере();
КонецПроцедуры

&НаСервере
Процедура ПоказатьНаСервере()
    
    // 1. Запрос к регистру
    Запрос = Новый Запрос;
    Запрос.Текст = 
        "ВЫБРАТЬ
        |   ДанныеРегистра.Ученик КАК Ученик,
        |   ДанныеРегистра.Поселок КАК Поселок
        |ИЗ
        |   РегистрСведений.Регистратор КАК ДанныеРегистра";
    
    РезультатЗапроса = Запрос.Выполнить();
    Выборка = РезультатЗапроса.Выбрать();
    
    // 2. Очищаем таблицу на форме
    ТаблицаРегистра.Очистить();
    
    // 3. Заполняем таблицу данными
    Пока Выборка.Следующий() Цикл
        НоваяСтрока = ТаблицаРегистра.Добавить();
        НоваяСтрока.Ученик = Выборка.Ученик;
        НоваяСтрока.Поселок = Выборка.Поселок;
    КонецЦикла;
    
    // 4. Сообщаем результат
    Сообщить("Найдено записей: " + ТаблицаРегистра.Количество());
    
КонецПроцедуры
